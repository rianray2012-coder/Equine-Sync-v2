# EquineSync UI System

> **Authority note:** `BRAND_AND_LOGO_GUIDE.md` is the authoritative source for palette and typography. `DESIGN_TOKENS.md` is reconciled to match it. This document describes the UI system intent.

## Brand Direction
EquineSync should feel: polished, calm, trustworthy, elevated, operationally clear, modern equestrian luxury.
Design style: **Apple × Equestrian Sports** (Eventing, Dressage, Show Jumping, English Pleasure).

Avoid: tech-bro aesthetics, overly playful design, cluttered dashboards, appearing snobby or unapproachable, overstated luxury (or direct use of the word "luxury").

## Color Palette (authoritative — Brand Guide 22)
**Primary Foundation**
- Midnight Graphite `#232734` — sidebars, headers, hero, dark UI surfaces, footers
- Slate Navy `#2E3550` — panels, navigation, interactive states, buttons, dashboard cards
- Frost White `#F7F8FA` — primary background, forms, light sections
- Platinum Mist `#E3E6EB` — cards, panels, dividers, table backgrounds, borders

**Accent System**
- Smoky Lilac `#B8AECF` — primary accent: highlights, buttons, key moments, notifications
- Frosted Lavender Gray `#D8D2E3` — hover states, subtle fills, soft backgrounds, empty states
- Ice Blue `#DCEAF4` — informational UI, charts, operational cues, data viz
- Glacier Silver Blue `#BCC9D6` — secondary chart elements, inactive states

**Status Colors**
- Success `#7FA98B` (muted sage)
- Warning `#D7B67A` (soft brass)
- Critical `#B46A6A` (muted oxblood)

**Gradients**
- Sidebar: `#232734 → #2E3550`
- Frost: `#F7F8FA → #ECEFF4`
- Lilac Atmosphere: `#D8D2E3 → #E8E3EF`

## Typography
- **Display:** Cormorant Garamond (SemiBold) — hero/marketing/headlines.
- **UI:** Inter — dashboard, forms, navigation, analytics, tables.
- Typography colors: Rich Charcoal `#1E2128` (primary), Muted Slate `#667085` (secondary), Soft Disabled `#98A2B3`.
- Prioritize clean spacing, hierarchy, legibility on mobile.

## Component Rules
- **Buttons:** consistent sizing, radius, hover states.
- **Cards:** soft shadows, generous padding, clean information hierarchy.
- **Tables:** mobile-friendly, collapsible when needed.

## Dashboard Philosophy
Dashboards should reduce overwhelm, surface priorities, support quick action.

## Mobile Rules
Primary workflows must be thumb-friendly, fast, low-friction. Core mobile actions: complete task, add note, upload photo, send update, check medication.
Operations must: handle interruptions without losing progress (screen timeouts, distractions), and operate without cellular/wifi (save progress and upload later).

## UX Tone
The platform should feel reassuring, operationally competent, emotionally calming. Owners should feel informed. Staff should feel organized. Managers should feel in control.
