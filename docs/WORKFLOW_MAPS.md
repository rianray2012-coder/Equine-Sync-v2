# EquineSync Workflow Maps

## Feeding Workflow
**Goal:** Ensure horses receive correct feed safely and consistently.
**Flow:** Barn Manager creates feeding instructions (AM/PM) → feeding tasks generated per horse → assigned to staff, visible to horse's owner → staff completes feeding → completion logged → exceptions flagged → management notified if issue occurs.
**Required features:** AM feed instructions (stalled / pasture, general), AM grain type/quantity/supplements/time, PM feed instructions/grain type/quantity/supplements/time, 24/7 hay access in stall (Y/N), hay net last filled, assigned hay type, assignment tracking, completion logs, issue reporting.
**Mobile priority:** Very high.

## Turnout Workflow
**Goal:** Coordinate safe and accurate horse turnout.
**Flow:** Turnout plan created → locations named → groups assigned → tasks generated → staff performs turnout → completion logged → incidents reported if needed.
**Required features:** warm-months plan (Mid Apr–Sept), cold-months plan (Oct–Mid Apr), turnout groups, day/night designation, restrictions, injury notes, weather alerts, buddy compatibility, placed-in-turnout tracking, stall-return tracking.

## Medication Workflow
**Goal:** Ensure safe medication administration with accountability.
**Flow:** Medication schedule created → tasks generated → assigned staff administers → completion logged → dosage/time recorded → missed-medication alerts triggered.
**Required features:** dosage tracking, frequency, administration logs, expiration tracking, alerts, audit logs.
**Compliance priority:** Critical.

## Stall Rest / Rehab Workflow
**Goal:** Coordinate recovery care clearly.
**Flow:** Trainer/Vet defines rehab protocol → restrictions assigned → rehab tasks generated → daily care tracked → progress updates recorded → owner visibility updated.
**Required features:** rehab instructions, hand-walking, restricted turnout, progress notes, owner updates.

## Owner Update Workflow
**Goal:** Build trust through consistent communication.
**Flow:** Horse activity completed → notes/photos added → trainer/manager reviews → owner summary generated → owner notified.
**Required features:** photos, summaries, training notes, incident visibility, media uploads.
**Emotional priority:** Very high.

## Incident Report Workflow
**Goal:** Ensure transparency and accountability.
**Flow:** Incident occurs → staff submits report → management reviews → owner notified if required → resolution tracked → audit log created.
**Required features:** injury reporting, timestamps, witness notes, media uploads, follow-up tracking.

## Training Workflow
**Goal:** Track horse development and rider progress.
**Flow:** Training session scheduled (assigned to horse, rider, or both) → session completed → trainer logs notes → progress goals updated → owner visibility updated → future plans documented.
**Required features:** ride notes, progression tracking, rider assignments, show preparation.

## Show Management Workflow
**Goal:** Coordinate competitions cleanly.
**Flow:** Show event created → eligible horses/riders notified → entries logged → entry forms/instructions provided → entry forms + vaccine records sent to show management → logistics assigned → billing tracked → schedules distributed → results logged → owner updates sent.
**Required features:** entries, hauling, stabling, attire, prep-week schedule, travel-day schedule, show-day schedule, ride times, coaching schedules, billing.

## Billing Workflow
**Goal:** Create transparent financial operations.
**Flow:** Charges generated → invoices created → owners notified → payments tracked → overdue alerts triggered.
**Required features:** recurring billing (boarding, full training, half training), custom charges (show coaching, hauling, sale/purchase commission), lesson charges (individual, small group, large group), show charges, payment status.

## Staff Task Workflow
**Goal:** Create standard operating procedures, simplify new-staff onboarding, increase accountability and operational visibility.
**Flow:** Tasks generated → assigned to staff → completed via mobile → completion logged → management visibility updated.
**Required features:** mobile completion, timestamps, notes, overdue tracking.
